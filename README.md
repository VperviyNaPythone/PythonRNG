# 🎲 PythonRNG

A simple and addictive RNG aura-rolling game built with Python and Tkinter, inspired by Sol's RNG.

## ✨ Features
* **Rarity System:** Roll for different auras from common ones up to the ultra-rare `BREAKTHROUGH` with unique sound effects and custom colors.
* **Gloves:** Equip a `Free Glove` or unlock the `Lucky Glove` using rare auras to boost your luck.
* **Auto-Roll & Quick Roll:** Automatic rolling mode and unlocked quick-roll speed after 500 rolls.
* **Inventory & Save System:** Your balance, total rolls, gloves, and collected auras are saved automatically between sessions.

## 🚀 How to Run (from source)
1. Download or clone this repository.
2. Install required libraries (e.g. `pygame` for audio):
   ```bash
   pip install pygame
   ```
3. Run the main script:
   ```bash
   python main.py
   ```
   *(Replace `main.py` with your main script's filename if it's named differently).*
